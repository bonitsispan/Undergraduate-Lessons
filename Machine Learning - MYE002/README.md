## Lesson Descreption
Introduction to the fundamental concepts and challenges of Machine Learning, including supervised and unsupervised learning, dimensionality reduction, and reinforcement learning. Topics covered include linear and logistic regression, classification methods (e.g., decision trees, SVMs, k-NN), neural networks, ensemble methods (e.g., random forests, boosting), clustering algorithms (e.g., k-means, DBSCAN), PCA/ICA, as well as Markov Decision Processes and reinforcement learning techniques.

## Project Descreption (Dimensionality Reduction and Clustering on CNN-Extracted Features)
This project explores the effectiveness of dimensionality reduction and clustering techniques applied to image features extracted from pretrained CNN models. Using features from MobileNet and ResNet50, we employed PCA, Locally Linear Embedding (LLE), and Autoencoders to reduce feature dimensionality. We then applied clustering algorithms including KMeans (with Euclidean and Cosine distance) and Agglomerative Clustering. Evaluation was performed using Silhouette Score, Purity, and F1-score across various configurations. The goal was to assess how different combinations of feature extractors, reduction methods, and clustering strategies affect unsupervised performance on binary image classification.
